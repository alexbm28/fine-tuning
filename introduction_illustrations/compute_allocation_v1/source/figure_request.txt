MATHEMATICAL SETUP

The empirical objectives are:

    R_pre(w)  = ||Xw - y||^2/(2n) + gamma*||w||^2/2

    R_fine(w) = ||X'w - y'||^2/(2n') + gamma'*||w||^2/2.

Their unique minimisers are w_hat and w_hat_prime.

For each feasible schedule:
- Run k pretraining GD iterations from zero, reaching w_k.
- Run ell fine-tuning iterations from w_k, reaching w'_ell.
- Enforce c_p*k + c_f*ell = B.

The ideal update is:

    Delta = w_hat_prime - w_hat.

The achieved finite-budget update is:

    Delta_{k,ell} = w'_ell - w_k.

Evaluate:

    f(k,ell) = ||Delta_{k,ell} - Delta||^2_{H'},

where:

    H' = X'^T X'/n' + gamma'*I.

THIS DISTINCTION IS ESSENTIAL

Do not replace this criterion with:
- ||w'_ell - w_hat_prime||^2;
- the empirical risk evaluated directly at w'_ell;
- a test-set prediction error;
- the distance to the data-generating teacher.

The ideal update Delta is independent of the allocation within each
fixed problem instance. Do not replace it with w_hat_prime - w_k.

The corresponding empirical excess-risk identity is:

    R_fine(w_hat + Delta_{k,ell}) - R_fine(w_hat_prime)
      = (1/2) ||Delta_{k,ell} - Delta||^2_{H'}.

Thus, the risk interpretation uses a COMMON ANCHOR w_hat.
The evaluated model w_hat + Delta_{k,ell} is generally not w'_ell.

Use “update error” in the figure rather than “downstream loss” or
“generalisation error”.

NUMERICAL EVALUATION

Prefer the existing stable implementation and saved objective values.

If recomputation is necessary, use the exact closed-form GD dynamics:

    C  = I - eta*H
    C' = I - eta'*H'

    w_k = (I - C^k) w_hat

    w'_ell = w_hat_prime + (C')^ell (w_k - w_hat_prime).

For accurate evaluation near convergence, use the residual identity:

    Delta_{k,ell} - Delta
      = [I - (C')^ell] C^k w_hat - (C')^ell Delta.

Do not evaluate tiny errors primarily by subtracting fully converged
parameter vectors. That can introduce cancellation and a false
floating-point error floor.

Preserve the existing thin-SVD or equivalent stable spectral treatment.
In particular, do not introduce spurious components of w_hat in the
kernel of X through numerical round-off and then allow those components
to dominate the asymptotic residual.

Use exponential rescaling and log-domain calculations where needed,
as in the original experiment.

Do not floor small positive errors to an arbitrary constant to make
the plot easier. Do not smooth the curves into an assumed U or V shape.
